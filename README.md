
# Домашнее задание 1 — алгоритмы на графах в Java

**ФИО:** Ермолаев Никита  
**Группа:** ПИ 2-1  
**Вариант:** 3 (C11)  
**Алгоритм:** Дейкстра  
**Тип графа:** ориентированный взвешенный  
**JDK:** 8 или новее

## Описание

Программа вычисляет кратчайшие расстояния от вершины A до всех
вершин графа, восстанавливает кратчайший путь A -> F и выводит
суммарный вес этого пути.

Для варианта C11 отрицательные веса заменены абсолютными значениями:
C -> B: 3, B -> D: 1, B -> E: 2.

## Структура проекта

- src/Vertex.java — вершина.
- src/Edge.java — ориентированное ребро.
- src/Graph.java — граф.
- src/Dijkstra.java — алгоритм Дейкстры.
- src/DijkstraResult.java — результаты и восстановление пути.
- src/Main.java — запуск основной программы.
- src/DijkstraTests.java — автоматические тесты.
- tests.md — описание проверок.
- report.docx — отчёт.

## Запуск основной программы

Откройте терминал в корневой папке homework1.

Скомпилируйте файлы:

    javac -encoding UTF-8 -d out src/*.java

Запустите программу:

    java -cp out Main

## Запуск тестов

    java -cp out DijkstraTests

Если все проверки пройдены, программа сообщит:
"Все 7 тестов пройдены."

## Ожидаемый результат

Кратчайшие расстояния от A:
A = 0
B = 7
C = 9
D = 8
E = 9
F = 11

Кратчайший путь A -> F: A -> B -> D -> F
Вес пути: 11
